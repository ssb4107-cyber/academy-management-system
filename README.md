# 학원관리시스템

Google Apps Script에서 Supabase + GitHub Pages 구조로 단계적으로 이전 중인 학원 운영 시스템입니다.

## 역할 분리

- GitHub Pages: 로그인과 학생 조회를 시작으로 이전되는 공개 화면
- Supabase: 로그인, 비공개 데이터, 사용자별 접근 권한, 서버 조회 함수
- Google Apps Script: 이전이 끝날 때까지 유지하는 현재 운영·검증 경로

학생 데이터, 스프레드시트 ID, 배포 ID, 비밀키와 환경파일은 GitHub에 저장하지 않습니다. 브라우저용 Supabase 공개 키만 소스에 포함되며 실제 데이터 권한은 로그인 JWT와 서버 함수가 결정합니다.

## 새 공개 화면

등록된 이메일로 로그인 링크를 받은 뒤 학생 목록과 월별 수납 내역을 조회할 수 있습니다. 학생 이름을 누르면 기존 대시보드와 같은 정보 항목을 균형 잡힌 상세 모달로 표시하며, 모달 안에서 해당 학생의 전체 수납 기록·휴가 관리·형제 관리 화면으로 이동할 수 있습니다.

수납, 학생 등록·수정, 휴가 등록·수정·휴지통 이동, 형제 그룹 설정·해제, 월별 형제 할인 변경은 Supabase 승인 요청으로 처리됩니다. 현금영수증 발급 명단은 기존 Google 원장의 발급번호·입금자명 구조를 유지한 채 최고 관리자 전용으로 조회·추가·수정·제외할 수 있고, 인쇄·PDF 저장용 3개월 확인란과 변경 이력을 제공합니다.

기간별 통계는 Google에서 계산해 저장한 2025-08~2026-10 학생별 월 스냅샷 1,905건을 보존하면서 현재 수납 1,206건과 급여 원장을 Supabase에서 결합합니다. 최고 관리자는 최대 36개월을 실제 납부일 또는 수납 귀속월 기준으로 조회하고, 월별 추이·원장/학년/결제수단·급여·미수금 상세를 확인하거나 CSV로 저장할 수 있습니다. 통계 안의 학생 이름도 공통 학생 상세 모달을 엽니다.

최고 관리자 승인 전에는 승인 대상 원장이 바뀌지 않으며 승인 결과, 변경 전후 값, 처리 계정이 감사 이력으로 남습니다. 익명 사용자와 미등록 계정은 서버에서 차단됩니다.

## 로컬 검사

```text
npm ci
npm run build
npm test
```

배포는 검사를 통과한 코드만 별도 승인된 로컬 환경에서 수행합니다. GitHub Actions에는 운영 비밀값을 넣지 않습니다.
